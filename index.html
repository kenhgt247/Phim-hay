Nhờ ChatGPT viết kịch bản đúng kiểu, đúng hình

Sổ tay biên kịch gồm cốt truyện, tính cách nhân vật, cách viết và danh sách chính xác mọi hình trong kho. Sổ tay tự cập nhật mỗi khi kho có thêm hình.

Cài một lần trong ChatGPT

  1. Bấm Tải sổ tay về bên dưới.
  2. Trong ChatGPT: Projects → New project, đặt tên Phim Hai Mặt.
  3. Vào project, mục Files → tải file SO_TAY_BIEN_KICH.md lên.
  4. Mục Instructions dán câu: Luôn viết kịch bản đúng theo file SO_TAY_BIEN_KICH.md. Chỉ dùng bối cảnh và tư thế có trong danh sách. Trả về một khối code.

Khi kho có hình mới, tải sổ tay về lần nữa và thay file cũ trong project.

Mỗi tập mới

  1. Dán câu lệnh vào project Phim Hai Mặt trong ChatGPT.
  2. Sao chép khối kịch bản ChatGPT trả về.
  3. Sang tab Kịch bản → + Tập mới → dán vào ô kịch bản → ▶ Dựng phim. Trang sẽ tự kiểm tra, sai tên hình ở đâu sẽ báo ngay.

Bấm vào một tư thế để chèn vào kịch bản đang mở (ở dòng con trỏ đang đứng). Hình có chữ mat là cảnh cận khuôn mặt.

Nhờ Gemini vẽ thêm hình vào kho

Mỗi hình tốn khoảng vài trăm đồng từ tín dụng Gemini. Vẽ xong (1–3 phút) hình sẽ có trong tab Kho hình.

Kết nối GitHub (làm một lần)

  1. Mở trang tạo mã truy cập của GitHub.
  2. Token name: Xuong Phim Hay. Expiration: chọn 1 năm (hoặc No expiration).
  3. Repository access: chọn Only select repositories → chọn Phim-hay.
  4. Permissions → Repository permissions: Actions = Read and write, Contents = Read and write.
  5. Bấm Generate token, sao chép mã (bắt đầu bằng github_pat_) và dán vào ô dưới.

Mã chỉ lưu trong trình duyệt của máy này, không gửi đi đâu ngoài GitHub. Dùng máy khác thì dán lại.
